## What the numbers say
- No crashes, NaN or non-ready bots in any mode. The act() 30 ms counts are isolated single ticks (31-95 ms) on different seeds, including 1-2 per set in mode 0, so machine spikes. Mode 5 on set 9000 had 11 matches with one tick over 30 ms (31-58 ms), against 0 for mode 6 and 2 for mode 0 on the same seeds. I did not rerun it (budget used), so I can't tell spike from cost. Flag 0 had a 95 ms tick on seed 3 that champion 4d6e71b did not have on the same seed (23.8 ms max), so a single slow tick is not attributable to the code. Sim-side answers over 50 ms (matches, sets 0/5000/9000/ext): mode 0 16/7/8/0, mode 5 0/7/27/-, mode 6 0/8/4/4; champion on set 0 had 1 match against 16 for flag 0 with identical code, so this wall-clock count is machine noise (my analysis scripts ran at the same time during some runs) and says nothing about the modes.
- Zone: zone deaths are 0-3 per 96 in every mode and the seeds mostly repeat across modes (63, 92, 5025, 5054, 9053 are baseline). Mode 5 has the most (3/3/2 vs 2/2/1): mode-5-only zone deaths 3, 89 (set 0), 5051 (5000), 9037, 9069 (9000). Mode 6 has fewer (1/2/0/0). Mode 5 also has more time outside the zone than mode 0 on sets 0 and 9000, fewer on 5000; mode 6 has less on sets 0 and 5000. These are 1-2 match differences; treat as noise-level.
- Pins on geometry: most pins are corner/pocket by my grid (>=8 of 16 headings 6 m out blocked; matches with such a pin, mode 0 / 5 / 6: set 0 4/4/3, set 5000 9/8/13, set 9000 8/5/3, extreme 4/-/3; see CSV rows `pin_episode_*`), in line with the earlier champion/B80 hazards. The long (>=20 s) pins are mostly the same seeds in every mode (41, 43 farm in open ground, 92, 72). Mode 5 and 6 remove some corner pins (16 and 79 on set 0, 5003, 9000, 9058 are mode-0-only) and add a few (72 on set 0 in both; 9095 in mode 5; extreme 2147483629 and 2147483636 in mode 6). Mode 6 set 5000 has the most pinned-in-zone matches (16 vs 12), with no pin >= 20 s. The only >= 20 s pin at a map edge is seed 92 (corner + map edge, modes 0 and 5; not mode 6). "Open ground, no solid within 8 m" pins (farm/loot, seeds 41, 43, 72, 79, 2147483636) mean the pin is not a building: could be terrain slope or a cube/NPC; my solid grid has no terrain slope.
- Oscillation: mode 6 is the big one: 44/42/49/17 matches vs 12/8/5/5 for mode 0 (mode 5: 19/12/10). Much of that is the combat strafe/orbit (by definition a strafe is >120 m path with <15 m net), but measure_movement's osc_windows_quiet (no enemy in view for half the window) is also higher: mode 0 21/7/4/0 windows, mode 5 216/13/69, mode 6 104/14/11/20. Mode 5 set 0 quiet-oscillation 216 windows vs 21 is the largest outlier. Per-seed breakdown is in the logs; I did not hunt the cause.
- Drop run: no ring hold was ever abandoned before capture in any mode (0 in all sets); every hold that started completed. The hold is also rarely reached (mode 0 8 holds in 336 matches, modes 5/6: 4 and 1). Drop walks are cut by higher-priority modes by design (engage, hurt, crossfire come first in brain.ts, drop run needs `!engage && !hurt && hp >= retreat HP`): in the champion too. The episode rate is dominated by one flip: drop-run walk -> "break crossfire" (2+ enemies in sight), 55 of 94 episodes in mode 0, 98 of 145 in mode 5, 96 of 131 in mode 6, median episode 1.1 s (mode 0) vs 0.4 s (modes 5/6): the bot flips between the two modes. Matches with >= 10 such flips: mode 0 0/2/0/1, mode 5 1/2/0/-, mode 6 2/1/0/1. Walk cut with a mech damage event within 2 s (under fire): 18 episodes in mode 0 (seeds 44, 63, 90; 5015, 5051, 5053, 5054; 9011, 9089; 2147483635/36), 10 in mode 5, 15 in mode 6. Mode-only under-fire seeds: mode 5: 72, 5023, 9002, 9087; mode 6: 72, 89, 5014, 5023, 5024, 5094, 9002, 9019. The episode counter is coarse (episodes merge across a 1-decision gap).
- Not found: no new class of pin or crash only in modes 5/6 beyond the above. Mode 6 reaching fewer ring holds and having 4x the oscillation windows are the two things I'd look at first.

## Limits
Sim only (house bots are invented); one run per config per set, so differences of 1-2 matches are noise. Pin classes use the sim's walk grid (walls inflated 3 m + map edge), no terrain slope. "Abandoned under fire" = mech `damaged` event (not zone/npc) within 2 s of the mode switch; the label comes from the bot's debug label, read in the wrapper, no repo change. Extreme set is 48 seeds from 2147483600 (it runs past 2^31-1; same in all modes).
